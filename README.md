## How I work

- **Start from the workflow.** Every tool above began as a process I ran by hand: quotes, scheduling, vendor follow-up, chasing invoices.
- **Keep the rules out of the model.** AI handles the conversation; code handles who can be texted, when, and what's bookable.
- **Ship, measure, adjust.** Put it in front of the business, watch what breaks, fix the next thing.
